生成结果

蓝色 图：… 和橘色 表情：… 是槽位：点击可从素材库选图、贴链接或上传本地图片。配好之后也能点图片再换（鼠标移上去会显示「点击更换」）。配错了用「重配全部」一键重来。复制时未填充的槽位会被跳过。

表情包库

存在本机浏览器（IndexedDB），不会上传。建议收集：微信文章里的小表情（右键复制图片地址，通常是 mmbiz.qpic.cn 开头，粘贴进文章后微信能直接识别）、自己做的 PNG/GIF。

批量总结公众号风格

粘贴同一公众号的多篇文章链接（每行一条，建议 3-10 篇），工具逐篇分析后汇总成风格文档。受限说明：微信不提供免登录的历史文章列表接口，链接需从公众号历史消息里复制。

风格总结

文章图片素材

粘贴公众号文章链接（支持一次贴多篇，每行一条），自动抓取文章并扒下所有图片（含正文配图、行内小表情），每张图标注原文上下文，写自己的文章时直接挑着用。图片存在本机 articles/ 目录。

分组用法：写某篇文章前，先抓 2-3 篇同题材参考文章放进同一个分组（比如「华为小米稿」），生成文章时自动配图只从这个组取图，匹配会准很多。

图池治理（去重与小图清理）

扫描全部已抓图片：同字节重复图（微信 CDN 同图不同链接很常见）与过小的配图（宽或高不足 200px）会稀释自动配图的命中质量。扫描只读不删；清理需你逐项确认。行内表情不受小图规则影响。

AI 接口设置

兼容 OpenAI 格式（阿里云百炼 DashScope 兼容模式、DeepSeek、Kimi、OpenAI 等均可）。Key 只保存在本机浏览器，走本地代理时不经过任何第三方。

风格档案备份

导出的 JSON 不包含 API Key。

数据存储（SQLite）

业务数据落在项目目录的 data/workshop.db（Python 标准库 sqlite3，无需安装数据库）。浏览器本地存储只当缓存：启动时以库为准同步，保存时异步回写。API Key 不入库，仍只留在本机浏览器。

盲评实验

从库里随机抽两篇同主题的生成稿并排展示，风格名与模型由服务端隐去，评委看不到来源。每篇打三个 1–5 分（5 最好，1 最差，每个维度下面写了 5/3/1 分别长什么样，照着打就行），再选更喜欢的一篇。结果写进 evaluation 表，和客观指标联表后可直接导出成论文用的对比表。

当前是 file:// 直开模式，没有本地服务，读不到库里的生成稿。双击 start.bat 启动后即可盲评。

盲评汇总
