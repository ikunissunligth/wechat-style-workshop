## 一句话结论

差评走的是「**零装饰排版 + 短段落 + 高频配图 + 行内小表情**」路线。
全文 0 个分割线、0 个引用块、0 个表格、0 个加粗、0 个自定义颜色、0 个 unicode emoji——
"活"的感觉全部来自：文字语气、梗图、35px 行内小表情。

## 正文 CSS 模板（66 个段落共用同一样式，可直接复用）

```css
p {
  font-size: 15px;            /* 比微信默认 17px 小一号，信息密度更高 */
  color: rgb(76, 76, 76);     /* 深灰而非纯黑，视觉柔和 */
  line-height: 1.75em;        /* 宽松行距 */
  margin-left: 8px;
  margin-right: 8px;          /* 左右各 8px 小边距 */
  text-align: justify;        /* 两端对齐 */
}
```

段落间距**不是用 margin 实现的**，而是插入统一样式的空 `<p>` 垫行（全文 70 个）。
这是微信公众号兼容性最好的间距手法——后台编辑器不认 margin-bottom。

## 图片用法三种

1. **头图 GIF**（1 张，430px 宽，ratio 0.4）：动图开场，品牌感
2. **满宽配图**（40+ 张，`width:100%`）：段落间的产品截图/梗图，紧跟在相关文字后
3. **行内小表情**（3 张 35px + 1 张 48px，方形 PNG）：
   嵌在文字段落里，例：「华为直接掏出了麒麟 9050 Pro 芯片！[表情]」
   尺寸严格控制在 35-48px，与 15px 正文形成明显层级

## 文字风格要点

- 口语梗密集：「华子」「尊」「嗷」「该说不说」「用魔法打败魔法」
- 省略号尾音用「。。。」（三个中文句号，不是省略号字符）
- 一段一个意思，段均 50 字，没有超过 3 行的段落
- 开头 hook + 主体逐产品过 + 结尾「差友们不见不散」互动收束

## 对自研编辑工具的启发

1. **「差评风」可以做成一键模板**：上面那段 CSS + 空段落垫行逻辑，就是一个
   preset。同思路可以抽「极简灰」「默认白」「卡片强调」等多个 preset。
2. **表情包的两种插入形态要有区分**：
   - 行内小表情（35-48px，方形，插在句尾）
   - 满宽梗图（独立段落，width:100%）
   现有 Markdown 系工具（doocs/md、墨滴）完全不支持前者——这是差异化点。
3. **图文节奏检查器**：扫描全文，若连续 >6 个段落无图则提醒插入——
   差评的实际节奏是每 2-6 段一图。
4. **空段落垫行要由工具自动生成**，不能让用户手敲回车。
